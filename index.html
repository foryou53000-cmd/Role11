💡 구글 Apps Script 연동 완료 상태

배포된 Apps Script 웹앱 URL이 자동으로 연결되어 있습니다. 페이지 진입 시 자동으로 시트의 최신 명단을 불러오며, 원할 때 언제든 상단 버튼으로 양방향 동기화(불러오기/저장)를 실행할 수 있습니다.

※ 새 버전을 배포하여 주소가 바뀌었을 경우 여기에 붙여넣고 [URL 설정 저장]을 누르면 localStorage에 즉시 반영됩니다. 
// 1. GET 요청 응답 규격 (시트 데이터 전송)
{
  "status": "success",
  "students": [{ "num": 1, "name": "김민준" }, ...],
  "roles": [{ "role": "칠판당번", "desc": "칠판 닦기" }, ...],
  "results": [{ "date": "...", "num": 1, "name": "김민준", "role": "칠판당번", "desc": "칠판 닦기" }]
}

// 2. POST 요청 전송 규격 (CORS 에러 방지용 text/plain)
{
  "action": "saveResults",
  "assignments": [
    { "num": 1, "name": "김민준", "role": "칠판당번", "desc": "칠판 닦기" }
  ]
}
